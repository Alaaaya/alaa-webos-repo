# Alaa webOS repo

Homebrew Channel > Settings > Add repository:
https://alaaaya.github.io/alaa-webos-repo/apps.json

Contains YouTube AdFree 0.6.0 with Harak, Aya and Velour themes (pick in the GREEN button settings). Same app id as the official one (youtube.leanback.v4), so it upgrades it.
Based on https://github.com/webosbrew/youtube-webos, GPL-3.0-only (see LICENSE). Source: https://github.com/Alaaaya/youtube-webos (branch mirsa/themes).
